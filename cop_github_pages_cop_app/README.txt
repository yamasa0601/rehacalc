# COP（重心動揺）解析：GitHub Pages / 静的サイト版

## できること
- CSVを読み込むだけで解析（ブラウザ内で実行）
- 前後N秒除外（既定 5秒）
- センタリング
- 10Hzローパス（既定 100Hzサンプリング時、SciPy butter(4, 0.2) と同係数 + filtfilt風）
- 95%信頼楕円面積（cm^2）
- 凸包面積（cm^2）
- Welch PSD（Hann, 50% overlap, detrend=mean）から 0–3Hz を100%に正規化した帯域比
  - LF: 0–0.3Hz
  - MF: 0.3–1.0Hz
  - HF: 1–3Hz（アプリ上はRPFとして表示）

## 置き場所
- リポジトリに `cop/` フォルダをそのまま置いてください（中に `index.html` と `copanalyze.js`）。

## 一覧ページからのリンク
- 一覧HTMLの `href` を `./cop/` にしてください。

## 注意
- GitHub Pagesは静的ホスティングなので、サーバー側のフォルダに自動保存はできません。
  出力は「端末にダウンロード」になります（EMGアプリと同じ想定）。
