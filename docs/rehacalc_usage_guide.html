評価記録・評価用紙PDF 作成手順

対象者情報の入力、各評価結果の送信、グラフ作成、評価用紙PDF出力までの初心者向け説明用紙です。

使用ページ
https://yamasa0601.github.io/rehacalc/
保存先
同じ端末・同じブラウザ内に保存されます。

個人情報を入力する場合は、共有PCや共有ブラウザでの使用に注意してください。ブラウザデータを削除すると保存記録も消えることがあります。

全体の流れ

  1. 評価記録ページで氏名またはID、基本情報、評価日、評価時期を入力します。
  2. BBS、歩行速度、筋力、GES、FAB、HDS-R・MMSEなどの各評価を実施します。
  3. 各評価画面の「評価記録へ送る」を押し、評価記録ページで対象者と評価時期を確認して保存します。
  4. 履歴・グラフで過去結果を確認し、折れ線グラフまたはレーダーチャートで説明します。
  5. 評価用紙PDFページで、評価用紙PDFまたはMMSE共通シートPDFを作成します。

1. 対象者の基本情報を入力する

評価記録ページを開く
  1. トップページから「評価記録・評価用紙出力」を開きます。
  2. 初回は「新規入力」のまま、氏名または対象者IDを入力します。
  3. 年齢、性別、身長、体重、術側、歩行補助具、術式など、必要な基本情報を入力します。

氏名が難しい場合はIDだけでも保存できます。PDFには入力した氏名またはIDが反映されます。

評価日と評価時期を決める
  • 評価日は実施した日付にします。
  • 評価時期は「入棟」「FAC3」「1M」「2M」「3M」「退院」から選びます。
  • 退院時の評価なら「退院」を選びます。
  • 同じ対象者で別の時期を入力すると、過去結果として並べて比較できます。

2. 各評価を実施して評価記録へ送る

基本操作
  1. トップページから実施したい評価を開きます。
  2. 評価を入力し、合計点や結果を確認します。
  3. 「評価記録へ送る」を押します。
  4. 評価記録ページへ戻ったら、対象者、評価日、評価時期が正しいか確認します。
  5. 「記録を保存」を押します。
評価評価記録へ送られる内容注意点
歩行速度（10mCWS）10mCWS m/s歩行速度ページから送信します。
筋力（HHD）入力した筋力項目のみ筋力一覧から、入力済みの項目だけ送信できます。
BBSBBS合計点評価記録の過去BBSを前回値として選択できます。
GESGES合計点評価用紙上ではmFES欄に反映されます。
FABFAB合計点各項目を入力して合計点を送信します。
HDS-R・MMSEMMSE合計点評価記録へ送るのはMMSEのみです。HDS-RはPDF出力用です。

すでに対象者が保存されている場合は、評価記録ページの「既存対象者から選択」で氏名やIDを選べます。

3. 保存と上書きの考え方

新しく保存する場合

別の評価画面から送った結果は、評価記録ページで「記録を保存」を押すまで履歴に残りません。送信後は必ず対象者と評価時期を確認して保存します。

編集して保存する場合

履歴の「編集」を押して開いた記録は、同じ記録を更新します。新しい記録として残したい場合は「新規入力」を押してから保存します。

同じ時期に複数評価を入れる場合

歩行速度、筋力、BBSなどを別々に保存しても、PDF出力時は同じ対象者・同じ評価時期の入力済みデータをまとめて反映します。

4. グラフを作成して説明する

折れ線グラフ
  1. 評価記録ページで「履歴・グラフ」を開きます。
  2. 対象者を選びます。
  3. グラフ形式を「折れ線グラフ」にします。
  4. グラフ項目で、BBS、10mCWS、MMSE、筋力など見たい項目を選びます。

折れ線グラフは、選んだ項目に入力がある記録だけを表示します。空欄の記録は0として扱いません。

レーダーチャート
  1. グラフ形式を「レーダーチャート」にします。
  2. レーダー種別で「総合5項目」または「筋力のみ」を選びます。
  3. 比較したい時期にチェックを入れます。
  4. 複数の時期を選ぶと、同じレーダー上に色分けして重ね表示されます。

総合5項目は、歩行速度、バランス、認知機能、遂行機能、注意機能の5角形で表示します。外側に近いほど、基準に対して良い結果です。

筋力のみを選んだ場合は、股屈筋、膝伸展、足背屈、股伸展、股外転、足底屈から表示したい筋力項目を選びます。選択中の筋力最大値を100%として、筋力のバランスや時期ごとの変化を確認します。

未入力の項目は描画しません。総合5項目は5項目すべて、筋力のみは3項目以上の入力があると説明しやすくなります。

臨床評価結果グラフ
  1. 評価記録にFAC、10mCWS、6分間歩行距離、ストライド変動係数、BBSを入力します。
  2. ストライド変動係数は「歩行加速度解析」から評価記録へ送信できます。
  3. 履歴・グラフの「臨床評価結果グラフ」で比較したい時期を選びます。

歩行自立度、歩行速度、歩行耐久性、歩行安定性、バランスの5角形で表示します。ストライド変動係数は低いほど外側に表示されます。

5. 評価用紙をPDF化する

評価用紙PDF
  1. 評価記録ページで「評価用紙PDF」を開きます。
  2. 対象者を選びます。
  3. 「評価用紙PDFを作成」を押します。
  4. 氏名またはID、基本情報、評価日、入棟・退院などの各時期の結果が評価用紙へ反映されます。
MMSE共通シートPDF
  1. HDS-R・MMSE共通シートで各項目を採点します。
  2. MMSEを評価記録へ送る場合は「MMSEを評価記録へ送る」を押します。
  3. 評価記録ページの「評価用紙PDF」から「MMSE共通シートPDF」を作成します。

評価記録へ送信されるのはMMSE合計点のみです。HDS-Rは共通シートPDFで使用します。

困ったとき

困りごと確認すること
PCだけ古い画面が出るページを閉じ、トップページから開き直します。BBSは「開く」ボタンの新しいリンクから起動します。
保存した結果が見つからない同じ端末・同じブラウザで開いているか確認します。別端末には自動同期されません。
PDFに反映されない評価画面で送信した後、評価記録ページで「記録を保存」したか確認します。
グラフに点が出ない対象者、グラフ項目、評価時期が合っているか確認します。未入力項目は表示されません。
